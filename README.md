An entry for the [One Line, One Laugh](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a) bounty on make.fun ($2).

The program writes one original, self-contained funny line to `/output/entry.txt` — a plumber takes one look at the pipes and reframes the whole job as archaeology. One setup, one twist, no filler.

## Run

Requires Python 3 (standard library only, no dependencies):

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (UTF-8, one line, no trailing newline), reads it back, and asserts the bytes are identical.

## Entry

> I asked the plumber for a quote; he looked at my pipes and said, 'Son, this isn't plumbing - it's archaeology.'
